# foodsharing-Logo

`foodsharing.png` ist das unverändert übernommene Original „logo standard 300dpi.png“ (1182 × 393) aus der offiziellen foodsharing-Mediendatenbank.

- Einstieg: https://foodsharing.de/content?sub=presse
- Material: https://media.foodsharing.de/?path=%2FMaterialienkatalog%2FLogo%2FLogo%20Braun%2FPNG&openfile=2711890
- Übernommen am 12.09.2026 zur Darstellung von foodsharing im Hackathon-Prototyp.
- Marken-/Urheberrechte verbleiben bei foodsharing.

Die übrigen Partner werden mit Namen und einer farblichen Gestaltung dargestellt; diese Karten sind keine nachgebauten Originallogos.
